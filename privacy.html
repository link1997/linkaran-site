隐私政策 / Privacy Policy

Hermes Agent · 最后更新 / Last updated: 2026-10-05

1. 概述 / Overview

Hermes Agent（下称"本应用"）是一个自托管的个人 AI 助手，运行在账号所有人的个人电脑上。 本政策说明本应用如何处理 Google 用户数据。本应用仅供账号本人使用， 不向公众提供服务，也不代表任何第三方处理数据。

Hermes Agent ("the Application") is a self-hosted personal AI assistant running on the account owner's own computer. This policy explains how the Application handles Google user data. The Application is used solely by the owner and is not offered as a public service.

2. 访问的 Google 用户数据 / Google user data we access

经账号本人授权后，本应用访问以下数据：

  • Google 日历事件数据（权限范围 https://www.googleapis.com/auth/calendar）： 事件的标题、时间、描述、地点、颜色等字段。

With the owner's explicit consent, the Application accesses:

  • Google Calendar data (scope https://www.googleapis.com/auth/calendar): event title, time, description, location, and color fields.

3. 数据用途 / How we use the data

上述数据仅用于：在账号本人的日历中创建、修改、着色或删除日历事件 （例如根据用户自己的指令录入活动日程）。数据不用于广告、画像、分析或任何其他用途。

The data is used solely to create, modify, color, or delete calendar events in the owner's own calendar, at the owner's own instruction. It is never used for advertising, profiling, analytics, or any other purpose.

4. 数据共享与转让 / Data sharing and transfer

本应用不向任何第三方出售、出租、转让或共享 Google 用户数据。 除为提供上述功能所必需（即调用 Google 官方 API）外，数据不外传。

The Application does not sell, rent, transfer, or share Google user data with any third party. Data leaves the machine only as part of calling Google's own APIs to perform the functions described above.

5. 数据存储与保护 / Storage and protection

  • OAuth 凭据（client secret、refresh token）仅保存在账号本人电脑的本地文件中。
  • 数据传输仅通过 HTTPS 与 Google 官方 API 端点进行。
  • 本应用不运营服务器，不在云端存储任何 Google 用户数据。
  • OAuth credentials (client secret, refresh token) are stored only in local files on the owner's own computer.
  • All data transmission uses HTTPS to official Google API endpoints.
  • The Application operates no server and stores no Google user data in the cloud.

6. 数据保留与删除 / Retention and deletion

本应用不保留 Google 用户数据的副本；所有日历数据始终保留在用户的 Google 账号中。 用户可随时通过下方方式撤销访问、停止本应用的一切数据访问。

The Application keeps no copy of Google user data; all calendar data remains in the user's Google Account. Access can be revoked at any time as described below.

7. 撤销授权 / Revoking access

可随时访问 Google 账号第三方访问权限页面 移除本应用的授权，授权移除后本应用立即无法访问任何 Google 用户数据。

8. Google API 服务用户数据政策 / Limited Use disclosure

本应用对 Google API 所获信息的使用与传输，遵循 Google API 服务用户数据政策， 包括其有限使用要求。

The Application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
