Hermes Agent

个人自动化助手 · Personal automation assistant

这是什么 / What is this

Hermes Agent 是一个自托管的个人 AI 助手，用于在本机自动化处理个人事务， 包括日程管理、信息整理、文件处理等。该应用仅供账号本人使用，不对外提供服务。 本网站为此应用的官方主页。

Hermes Agent is a self-hosted personal AI assistant that automates personal tasks on the owner's own machine, including calendar management, information organization, and file processing. The application is for the owner's own personal use only and is not offered as a service to others.

Google 账号授权 / Google Account Authorization

本应用在获得账号本人明确授权后，可访问其 Google 日历数据， 用于创建、修改和整理日历事件。授权是自愿的，可随时撤销。

  • 请求的权限范围：https://www.googleapis.com/auth/calendar（日历事件读写）
  • 数据用途：仅为账号本人在其自己的日历中添加/调整事件
  • 数据共享：不向任何第三方出售、转让或共享
  • 数据存储：仅保存在运行该助手的本机

This application accesses the owner's Google Calendar data only after the owner explicitly grants permission, and only to create and adjust calendar events. Access is voluntary and revocable at any time. Data is never sold, transferred, or shared with third parties.

撤销授权 / Revoking access

可随时在 Google 账号权限页面 撤销本应用的访问权限。
